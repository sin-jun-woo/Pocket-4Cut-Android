# Instagram campaign generation

Built-in image generation tool, 2026-09-22. Four input references are the actual final Android-rendered spring/summer/autumn/winter `deliverables/examples/*/four_vertical.jpg`. These contain previously generated fictional adults, not customer or user photographs. The output is a campaign illustration/print mockup, not a literal app screenshot. App screenshot proof is separately in `verification/autumn-picker-compose.png`.

The returned master is preserved as `instagram-promo-master.png`. Delivery is an sRGB, opaque 1080×1350 PNG produced by mechanical resize. No manual repainting. No platform posting has been performed.

Input images1 through4 are exact product references: spring, summer, autumn, winter ACTUAL Pocket4Cut four-photo strips respectively.
