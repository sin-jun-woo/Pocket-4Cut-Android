# 보류된 카메라 + 인화지 초안

2026-09-10 사용자 피드백으로 채택하지 않은 v2 초안이다. 앱과 스토어의 현행 아이콘이 아니다.

- 카메라·렌즈·셔터·네 컷 인화지 벡터를 제작하고 밀도별 자산 및 APK 빌드를 확인했으나, 사용자가 카메라 일러스트 중심 방향을 원하지 않아 적용을 철회했다.
- `previous-icon/`은 v2 작업 직전 적용된 v1 아이콘 파일 21개의 백업이다. 이 백업을 기준으로 앱 자산을 복구했다.
- 이 폴더의 PNG와 `icon-validation.json`은 초안 자체의 검증 기록이다. 최종 납품 파일로 사용하지 않는다.
- `render-icons.cjs`는 앱 벡터가 이 초안과 일치해야 실행되는 도구다. 실행을 위해 현행 앱 자산을 v2로 다시 바꾸지 않는다.
- 후속 방향은 실제 네 컷 인화지 중심에 필름 가장자리·프레임 경계 요소를 더하는 것으로 재검토 중이다.
