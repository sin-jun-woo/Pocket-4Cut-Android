# 보류된 숫자 4 심볼 초안

2026-09-10 사용자 피드백으로 채택하지 않은 v3 초안이다. 앱과 스토어의 현행 아이콘이 아니다.

숫자 4의 기둥을 네 구간으로 나누는 방향을 검토했으나, 사용자는 숫자 중심보다 인생네컷·필름 사진의 직접적인 형태를 요청했다. SVG와 PNG는 비교용 작업 이력으로만 보존한다. 밀도별 런처 자산을 생성하거나 최종 패키지에 포함하지 않았다.

중간 적용했던 SVG/XML도 마지막 납품본 v1 자산으로 되돌렸다. `previous-icon-v2/`는 비교용 카메라 초안 백업이며 현행 아이콘 백업과 혼동하지 않는다.
