정확한 크기와 사진 칸 좌표는 manifest.json에 있습니다.

3. 날짜와 특수 프레임
예시 날짜는 2026.09.23입니다. 연도, D+100, 10번째, 장소, 날씨, 온도, 이름, 문구는 디자인 예시입니다.
이 PNG만으로 날짜·위치가 자동 변경되는 것은 아닙니다. 자동 계산·위치 입력 등은 이후 앱 구현 범위입니다.
실제 적용 시 source/catalog.json 및 렌더 입력과 함께 원하는 값으로 바꿔야 합니다.

4. 사진 예시
examples/의 이미지는 사진 비율과 장식 배치를 보기 위한 합성 예시입니다.
이전 프로젝트의 가상 성인 생성 사진을 재사용했으며 실제 사용자 사진·실제 기념일 기록·고객 후기가 아닙니다.
아기·반려동물 등 대상이 다른 주제의 실제 활용 예시로 해석하지 마세요. 실제 이용할 때는 원하는 사진을 넣으시면 됩니다.

5. 출처와 원본
기념일별 장식은 내장 전용 이미지 도구로 별도 생성했습니다. 원본·정확한 요청은 source/masters, source/prompts에 보존합니다.
사진 칸, 글자, 브랜드와 기하 패턴은 코드로 배치했습니다. 사람이 직접 그린 그림이라고 주장하지 않습니다.
원본 알파를 보존해 크롭·축소·배치했으며 체크무늬를 투명도로 위장하지 않았습니다.
기존 앱 출력 manifest의 좌표를 사용한 정적 디자인입니다. 이번에 Android를 실행한 출력물이 아닙니다.
광복절 태극기는 행정안전부 공식 도안을 사용했습니다. 출처: https://www.mois.go.kr/frt/sub/a06/b08/nationalIcon_2_2/screen.do

기존 사계절 프레임과 사진은 변경하지 않았습니다.
