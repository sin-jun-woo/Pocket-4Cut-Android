## 2026-09-23 정적 납품 당시 범위

- **프레임 이미지 제작만** 진행합니다. 앱 코드·선택 UI·카메라·저장 로직은 변경하지 않습니다.
- 사용자의 지시에 따라 앱 빌드·단위 테스트·계측 테스트를 실행하지 않습니다. 이미지 제작 과정의 육안 검수와 파일 출력은 별개입니다.
- 내장 전용 이미지 도구로 주제별 별도 일러스트 원본을 생성합니다. 도구가 모델명/품질 선택 옵션을 노출하지 않으므로 특정 최고 모델을 선택했다고 주장하지 않습니다.
- 장식은 생성 이미지, 정확한 글자·사진 칸·선·브랜드는 데이터와 코드로 구성합니다. 생성 이미지의 출처를 사람이 직접 그린 것으로 표시하지 않습니다.
- 기존 앱에서 출력한 Paper Seasons `manifest.json`의 **현재 8배치**, **문구 공간 변형 8배치**, **이전 6컷 호환 2배치**를 재사용했습니다. 주제마다 18개의 사진창 투명 PNG, 총 1,584장입니다. 이것은 이번에 Android를 실행한 결과가 아니라 저장된 앱 좌표를 이용한 정적 디자인입니다.
- 날짜·시간·D-Day·온도·장소·이름 등의 이미지는 **예시 값**입니다. 현재 앱 통합에서도 이런 값을 자동 계산하거나 가져오지 않으며 기존 문구·날짜 편집에서 사용자가 직접 기록합니다.

## 원본과 분류

`source/catalog.json`은 사용자의 88행을 고유 ID와 원래 명칭으로 관리합니다. 유사 항목도 합치거나 누락하지 않습니다. 예를 들어 여름휴가/바캉스, 월간 기록/이번 달의 네컷은 각각 별도 원본을 만듭니다.

새 파일은 기념일·러브·프렌즈·홀리데이·트래블·라이프·이벤트·패밀리·메모리·커스텀의 **10개 폴더**로 분류합니다. 기존 시즌 4종은 [Paper Seasons](../../seasonal-frames/paper-seasons-v1/README.md)에 그대로 보존합니다. 현재 앱은 이 10개 카테고리 필터와 88종 선택을 제공하며 검색·즐겨찾기·최근 선택은 제공하지 않습니다.

생성 원본은 `source/masters/`, 정확한 요청은 `source/prompts/`, 기계적 크롭·투명 여백 정리본은 `source/atlases/`, 결과 PNG는 `deliverables/frames/<category>/<index-id>/`에 둡니다. 원본의 알파와 색을 보존하며 일러스트를 다시 그리거나 색을 임의 치환하지 않습니다.

슬롯·텍스트 기하를 조합하는 `source/render-collection.cjs`는 기존 Node의 `@napi-rs/canvas`와 `sharp`를 사용하며 새 의존성을 앱에 추가하지 않습니다. 폰트는 기존 앱 폰트와 로컬 설치 폰트로 래스터화하고 별도 폰트 파일을 패키지에 배포하지 않습니다.

## 분위기와 제작 규칙

장식의 수를 늘리는 것보다 **색감·주제 소품·여백·글자가 함께 만드는 분위기**를 우선했습니다. `source/art-direction.json`에 88종 각각의 방향과 타이포그래피·장식 밀도를 기록했습니다.

- 생일은 크림·레드와 케이크, 웨딩은 아이보리·식물색과 초대장 같은 여백, 졸업은 학사모·짙은 초록과 단정한 글자를 사용합니다.
- 여행·개인 기록은 티켓/노트 같은 모노스페이스와 가는 선, 스포츠는 굵은 제목과 핀스트라이프, 전통 기념일은 한글과 한지 계열 색을 씁니다.
- 반려동물 추억·오늘 기록은 작은 대표 상징과 조용한 여백으로 사진을 우선합니다. 여섯 원본 소품을 모든 배치에 전부 넣지 않습니다.
- 사진 창·제목·브랜드·선은 정확한 데이터로 배치하고, 창 안에 장식을 겹치지 않습니다. 장식의 흰 부분을 배경으로 오인해 지우지 않고 원본 알파를 보존합니다.
- 긴 리본·가지 때문에 격자를 넘는 6종은 `source/roi-overrides.json`의 독립 영역·다각형으로 끝부분을 보존했습니다. 전체 원본은 수정하지 않았습니다.
- 광복절의 태극기만 [행정안전부 공식 도안](https://www.mois.go.kr/frt/sub/a06/b08/nationalIcon_2_2/screen.do)을 사용합니다. 도안 원본·출처는 `source/references/`에 보존했습니다. 기타 주제 장식은 독립 생성 이미지입니다.

## 파일 규격

- 주제별 생성 마스터 88장: 1536×1024 RGBA PNG. 정리 아틀라스 88장도 같은 크기입니다.
- 완성 PNG 1,584장: 8bit RGBA, 사진 창 실제 투명, 레이아웃에 따라 폭 1248–4992px / 높이 1878–4971px. 정확한 조합은 manifest에 있습니다.
- 테마별 8배치 모아보기 88장: 2400×2100 JPG. 카테고리 10장 + 전체 88종 1장도 제공합니다.
- 사진 합성 예시 88장: 폭 1175px JPG. 기존 가상 성인 사진을 이용한 비율/배치 예시일 뿐, 아기·반려동물·부모님 주제의 실제 사진이나 고객 후기가 아닙니다.
- 인스타그램 1종: 1080×1350 PNG 및 2160×2700 마스터. 생성한 종이 배경에 **실제 완성 프레임 3개와 기존 가상 사진**을 합성했습니다. 프레임 장식이나 사진을 다시 생성해서 바꾸지 않았습니다. 게시·광고 집행은 하지 않았습니다.

## 출력 재현

정적 납품 전체를 다시 출력하려면 `sharp`, `@napi-rs/canvas`, `jszip`이 필요합니다. 앱 런타임 WebP 내보내기와 검증에 필요한 Node 패키지는 `source/package.json`과 잠금 파일로 별도 고정합니다. 앱 의존성 설치나 Gradle 실행은 필요 없습니다. Windows의 Georgia·Malgun Gothic·Consolas와 저장소의 배민 한나/연성 폰트를 사용합니다. 타 운영체제에서는 동일 글꼴을 준비하지 않으면 글자 모양이 달라질 수 있습니다.

저장소 루트에서 실행합니다.

```powershell
node design/occasion-frames/everyday-editions-v1/source/render-collection.cjs
node design/occasion-frames/everyday-editions-v1/source/render-promo.cjs
node design/occasion-frames/everyday-editions-v1/source/package-collection.cjs
```

한 테마만 다시 출력할 때는 `--theme birthday --force`를 사용합니다. 특히 ROI만 바꾸었을 때도 `--force`로 해당 테마를 다시 출력해야 합니다. PNG 전체 출력 뒤 홍보 이미지, 모아보기와 ZIP을 순서대로 만듭니다. 생성 모델을 다시 호출하는 스크립트가 아니므로 보존된 마스터가 필요합니다.
