# 88종 프레임 내레이션

기존 reference-v3와 seasonal-v4에 사용한 사용자 승인 6초 참조 WAV와 대본을 로컬에서 재사용한다. 참조 WAV 해시는 `879cebf255d781553ade92ed00bd25d50f7298884423d295830876d24fe253d8`로 이번에도 대조했다. 다른 사람의 음성으로 교체하지 않으며 참조 파일은 배포하지 않는다.

로컬 Qwen3-TTS-12Hz-1.7B-Base, CPU float32/SDPA, Korean, 6스레드, seed 91026, 참조 대본 포함 조건을 그대로 사용한다. 모델·패키지 버전은 `verification/local-voice-job.json`에 실제 실행 결과로 남는다. 다운로드·설치·외부 추론 전송 없이 기존 독립 환경을 사용한다. 모델 라이선스 표기 Apache-2.0은 참조 음성이나 생성 결과의 상업적 권리를 별도로 보증하는 것은 아니다. 사용자의 AI 음성이라는 설명을 독립적으로 검증했다고 주장하지 않는다.

발화를 자르거나 배속하지 않는다. 0.12초 시작 여유, 끝 안내 여유, 48kHz stereo PCM24 마스터, 음량 목표 −16LUFS/TP −1.8dB를 적용한다. 음악·효과음은 넣지 않는다.

로컬 whisper.cpp b4938/small-q5_1로 정답 프롬프트 없이 전사한다. 공백·문장부호·대소문자와 컷/장/가지 앞의 1·2·4·6·8·88 숫자 표현만 정규화한다. 두 자리 88의 각 숫자에 원본 글자 위치를 유지해 이후 문장의 타이밍을 밀지 않는다. 숫자 내용·브랜드·다른 단어의 오류를 정답으로 고치지 않는다. 불일치 시 렌더링을 막는다.

ASR 일치·파형·음량 검사는 주관적 청취나 원본 음색의 완전한 동일성 평가가 아니다. 본편/MP3를 휴대전화에서 들어본 뒤 게시하는 것을 권한다. 실제 실행 길이·해시·전사·타이밍·규격은 새 `verification/` 결과가 기준이며 옛 영상의 검증 결과를 재사용하지 않는다.

## 이번 생성 과정의 수정

1차 대본의 `포켓네컷에`가 실제 ASR에서 `포켓네컷의`로 인식되어 전체 정규화 비교가 1글자 불일치했다. 해당 시도의 렌더는 차단됐다. 둘을 같은 단어로 바꾸는 예외를 넣지 않았으며 원문과 원음은 ignored build의 attempt-01에 보존했다. 문장을 `포켓네컷, 여든여덟 가지 프레임이 생겼어요.`로 명확히 바꾸고 전체 음성을 다시 생성했다. 2차는 원음20.24초, 정규화127글자·edit distance0, 14장면 타이밍으로 통과했다. 최종 결과와 이력은 새 job/ASR 및 `verification/narration-attempts.json`을 따른다.

현재 모델 및 speech tokenizer 파일 SHA-256을 이전 지정 값과 다시 대조하여 일치를 확인했다. SoX/flash-attn 부재 경고가 있지만 기존 CPU/SDPA 로컬 경로는 실행되었다. 설치하거나 다른 화자로 대체하지 않았다.
