## 실제 자료와 표현의 경계

시즌별 인화사진은 `design/seasonal-frames/paper-seasons-v1/deliverables/examples/`의 실제 Android CollageRenderer JPEG다. 모두 기존 가상 성인 사진을 사용하며 실사용자의 사진이나 후기라고 주장하지 않는다. 새 생성 포스터를 앱 화면처럼 보여주지 않는다. 저장/공유 동작 영역은 기존 코드 기반 UI 자료를 최소한으로 재사용한다. 영상은 편집된 홍보물이며 실기기 연속 녹화가 아니다.

프레임 네 종류와 배치 여덟 종류를 구분한다. 조합은 32종이며 배치 자체가 32개라는 뜻이 아니다. 무료, 광고 없음, 특정 촬영 시간, 성능 향상 등 확인하지 않은 장점을 덧붙이지 않는다. 앱 코드나 배포 상태를 이 영상 작업으로 바꾸지 않는다. 게시 전에 새 프레임이 실제 배포 앱에 반영됐는지 확인한다.
