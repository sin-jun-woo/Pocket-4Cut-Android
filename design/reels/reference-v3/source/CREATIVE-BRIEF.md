## 반영한 최신 요청

제공된 영상은 음색 참조로 사용한다. 새 광고는 원본 의류 광고의 대사나 전개를 옮기는 작업이 아니다. 사용자 수정 요청에 따라 포켓네컷을 소개하는 자체 흐름, 친근한 존댓말, 음악 없는 내레이션 중심으로 제작한다. 참조 계정명·영상·문구·출처 자막을 광고 화면에 삽입하지 않는다.

첫 문장은 “내 폰이 네 컷 사진관이 된다면요?”다. 설명을 기다리게 하지 않고 첫 프레임부터 완성된 네 컷 사진을 크게 보여준다. 이어 앱 이름 → 4컷 선택/8장 자동 촬영 안내 → 4장 선택 → 배치와 필터 → 흑백 결과 → 저장·공유 → 사용할 상황 → 브랜드 검색으로 연결한다. 특정 사용자의 후기를 가장하지 않는다.

## 화면 언어

- 큰 필름 사진, 종이색 `#F0ECE3`, 먹색 `#252520`, 제한적인 적색 `#C83D2D`를 사용한다.
- 과한 둥근 카드·기기 목업 대신 실제 앱 화면을 필요한 조작 영역만 확대한다. 원래 앱 UI의 둥근 요소를 영상 작업을 이유로 변경하지 않는다.
- 얇은 외곽선과 그림자가 있는 짧은 자막을 사진 위에 배치한다. 메뉴를 보여줄 때는 메뉴를 가리지 않는 위치로 옮긴다.
- 흑백 소개 이후 저장·공유 장면도 동일한 흑백 결과를 유지한다. 컬러 원본 필터 선택 행을 흑백 결과와 함께 표시하지 않는다.
- 자막과 장면 전환은 새 음성의 자동 전사 시각을 기준으로 맞춘다. 타이밍이 없는 초안은 최종 영상으로 납품하지 않는다.

## 기능과 근거의 경계

기존 실제 Compose 코드 기반 호스트 렌더와 CollageRenderer의 결과, Film Strip v4 아이콘, 가상 성인 예시 사진을 재사용한다. 재료 경로·해시는 `../visual-stills/input-manifest.json`에 기록한다. 새 사진·아이콘·프레임을 생성하지 않는다.

4컷 선택 시 8장 촬영 안내, 선택·배치·필터·저장·공유에 한정해 소개한다. 무료 여부, 광고 유무, 촬영 소요 시간, 미검증 편집 기능이나 성능을 추가 장점으로 주장하지 않는다. 프레임 색과 필터가 결합된 예시는 단일 변수 비교가 아니다. 촬영 장면은 안내 화면의 편집 예시이지 실제 연속 촬영 녹화가 아니다.

이번 방향은 사용자가 제공한 구체적 참조와 후속 수정 요청을 우선한다. 이전 v2의 트렌드 조사로 이번 새 음색을 검증했다고 주장하지 않으며, 유행 순위·세대 전체 선호·광고 성과를 보증하지 않는다. 후속 요청에 따라 본편과 커버의 상·하단 설명 오버레이를 제거했다. 생성 도구·재료에 관한 제작 기록은 별도로 보존한다.
