# Pocket4Cut 릴스 오디오 — Four little moments

2026-09-10 / Asia/Seoul. 이 릴스에 맞춰 JavaScript 신시사이저로 제작한 오리지널 절차적 음악·효과음이다. 녹음된 아티스트 곡, 전문 스튜디오 세션, 전용 생성형 음악 도구의 출력이라고 표현하지 않는다.

## 제작과 권리 범위

- 외부 곡, 샘플, MIDI, 녹음, 음성, 음원 라이브러리 또는 임펄스 응답을 사용하지 않았다. 외부 패키지 없이 Node.js 표준 라이브러리만 쓴다.
- 제작 코드와 고정 난수 시드로 재현한다. 특정 곡의 선율·음원·연주를 복제하지 않았다. 오리지널 제작 방식의 기록이며 저작권 등록 가능성이나 플랫폼의 자동 권리 판정을 보장하는 법률 의견은 아니다.
- 영상과 함께 배포할 수 있도록 만든 프로젝트 자산이다. 제3자 곡이나 유행 음악을 가져왔다는 의미의 “트렌딩 오디오” 표시는 사용하지 않는다.
- `node design/reels/film-story-v1/source/make-audio.cjs`로 아래 세 WAV를 다시 만든다. 앱 코드·앱 내 소리를 변경하지 않는다.

## 사운드 방향

120 BPM, 4/4 박자, 15마디(60박), 정확히 30초. 따뜻한 전자피아노와 열린 9th 코드, 단정한 저음, 스윙이 있는 가벼운 2-step 리듬으로 네 컷 사진의 경쾌함을 표현한다. 광고 문구를 방해하는 보컬이나 계속 반복되는 고음 리드는 넣지 않았다.

FM 전자피아노는 짧은 어택과 감쇠, 미세한 디튜닝을 사용한다. 베이스는 중앙에 두고 화음·리듬의 일부만 좁게 패닝한다. 드럼은 사인파 피치 스윕과 필터링된 노이즈로 합성한다. 작은 필터드 피드백 룸 잔향과 DC 제거, 시작/종료 페이드를 적용한다. 외부 앰비언스 또는 실제 카메라 녹음은 없다.

- 0–2초: 부드럽게 시작하며 셔터 세 번으로 도입의 컷 전환을 강조한다.
- 2–24초: 사용법 구간을 받치는 가벼운 리듬. 짧은 전자피아노 응답구는 빈 공간에만 배치한다.
- 24–28초: 드럼과 베이스를 덜어 CTA 문구에 여유를 준다.
- 28–30초: 마지막 Dmaj9 코드와 잔향. 29.15초부터 완만한 페이드 후 마지막 샘플은 0이다.

영상 편집 기준 효과 시각: 셔터 0.5 / 1 / 1.5 / 3 / 10 / 16 / 24초, 종이 이동 6 / 13 / 20초. 효과는 전부 합성된 짧은 사운드 디자인이며 실제 기기 셔터음이 아니다.

## 출력과 검증

- `audio/pocket4cut-original-30s.wav`: 음악과 효과음이 함께 들어 있는 영상용 완성 믹스.
- `audio/music-only.wav`: 별도 음악 스템.
- `audio/sfx-only.wav`: 음악 없이 같은 시각과 같은 레벨로 배치한 편집용 효과 스템. 단독 피크 정규화하지 않는다.
- 공통 규격: 48,000 Hz, 2채널, 16-bit signed PCM WAV, 1,440,000 sample frames, 30.000초, 파일당 5,760,044 bytes.
- 합산 믹스의 목표 sample peak는 −3.1 dBFS이다. 클리핑·NaN/Infinity 검사는 생성 코드가 실패로 판정한다.
- 생성 시 실제 PCM 기준 peak/RMS/DC/stereo correlation 및 SHA-256을 표준 출력으로 보고한다. 이 수치 검사는 통합 LUFS, inter-sample true peak, 실제 휴대전화 청취 또는 주관적 음악 품질 검증과 다르다.
- 비디오 AAC 변환 후에는 mux된 오디오의 길이·동기·피크를 다시 확인해야 한다. 새 곡/보이스오버를 더할 때는 전체 믹스 레벨을 다시 조절한다.

### 이번 실행 결과

`node --check`와 생성 명령이 종료 코드 0으로 완료되었다. 출력 파일을 다시 읽어 WAV 헤더, 길이, 마지막 프레임의 0값을 독립 검사했다. 완성 믹스와 두 스템의 합은 PCM16 양자화 오차 1단위 이내로 일치한다.

- 완성 믹스: peak **−3.100 dBFS**, RMS **−17.672 dBFS**, clipping **0**, DC offset **−0.000001097**, 스테레오 상관계수 **0.964870**.
- 음악 스템: peak **−3.100 dBFS**, RMS **−17.673 dBFS**, clipping **0**.
- 효과 스템: peak **−22.033 dBFS**, RMS **−56.199 dBFS**, clipping **0**. 30초의 대부분이 무음이므로 전체 RMS가 낮다. 처음 유효 신호는 0.500021초이며 합성 효과 타이밍과 일치한다.
- 완성 믹스 SHA-256: `4a05a4f63cb2b8906f442dff96ae7165ce4715972a33f9734bd40899538f1ab0`.
- 음악 스템 SHA-256: `bf1c70ba91909f3d59da5eea995e44f9a1ab6ac3951685befee2554085b51385`.
- 효과 스템 SHA-256: `7a394edcb765b1d0fc48ac030d999cb59a6081395581937db147f2b0d80f1def`.

청취 환경에 따른 최종 품질·휴대전화 스피커 재생은 별도 확인 대상이다. 이 문서는 청취하지 않은 상태를 청취 완료로 주장하지 않는다.

### 최종 MP4 측정

`export-reel.cjs`에서 두 스템 선택본에 동일하게 +1 dB를 적용하고 AAC 192 kbps / 48 kHz stereo로 인코딩했다. FFmpeg `ebur128=peak=true`로 최종 MP4에서 다시 측정한 결과는 완성본 **−15.3 LUFS / −2.1 dBTP**, 음악 없는 효과음 전용본 **−42.0 LUFS / −20.6 dBTP**다. 효과음 전용본은 대부분 무음이어서 통합 음량이 낮으며 별도 배경음 추가용이다. 두 영상 모두 오디오/비디오 길이 30.000초, 전체 디코딩 오류 0이다. 수치 검증은 실제 스피커 청취와 별개다.
