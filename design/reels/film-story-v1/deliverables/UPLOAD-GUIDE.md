# Pocket4Cut 릴스 업로드 파일

## 바로 사용할 파일

- **Pocket4Cut-Reels-30s.mp4**: 전용 음악과 셔터·종이 전환 효과음이 포함된 완성본. 기본 추천 파일입니다.
- **Pocket4Cut-Reels-30s-NoMusic.mp4**: 동일한 영상에 효과음만 포함한 버전. 계정에서 사용 허가를 확인한 음악을 별도로 붙일 때 사용합니다. 완전 무음 파일은 아닙니다.
- **Pocket4Cut-Reels-Cover.jpg**: 1080×1920 커버 이미지. 업로드 화면에서 표지로 선택하고 프로필 썸네일 자르기를 확인하세요.
- **INSTAGRAM-CAPTION.txt**: 복사해서 사용할 게시글과 해시태그 초안.
- **CAPTIONS-KO.srt**: 재편집용 한국어 자막 타임코드. 영상에 이미 큰 자막이 들어 있으므로 다시 겹쳐 넣을 필요가 없습니다. 보이스오버 녹취가 아닙니다.

두 MP4는 9:16 / 1080×1920 / 30 fps / 30초 / H.264 High / AAC 48 kHz stereo입니다. 추가 앱 설치나 편집 없이 영상 파일 자체를 재생할 수 있습니다.

## 게시 직전 확인

1. 먼저 음악 포함 MP4를 휴대전화에서 재생해 실제 스피커 음량과 처음부터 끝까지의 흐름을 확인하세요. 파일 디코딩·음량 수치 검사는 했지만 휴대전화 청취는 대신할 수 없습니다.
2. 릴스 업로드 미리보기에서 우측 아이콘·하단 계정/설명/광고 버튼이 자막을 가리지 않는지 확인하세요. 핵심 자막은 여백을 두었지만 기기·표시 방식별 UI가 동일하다고 보장하지 않습니다. 화면을 가득 채우려고 추가 확대하지 않는 편이 원본 구성을 유지합니다.
3. 커버의 제목과 Pocket4Cut 이름이 현재 프로필 썸네일에 함께 보이도록 자르기를 조정하세요. 릴스 본문 9:16과 썸네일 자르기는 별개입니다.
4. 게시글의 실제 앱 이름·스토어 검색 결과·배포 버전 1.3 화면을 직접 확인하세요. 이번 제작에서 Google Play의 실시간 노출/지역별 설치 가능 여부를 확인하지 못했습니다. 실제 스토어 링크가 확인되면 프로필 링크에 연결할 수 있습니다.
5. 생성 사진 고지를 유지하고, 게시 화면에 표시되는 AI 콘텐츠 관련 항목을 검토하세요. 영상 속 인물은 기존 프로젝트의 AI 생성 가상 성인 예시이며 실제 이용자 후기나 앱 카메라의 촬영 품질 증거가 아닙니다.

## 음악과 시연 범위

완성본 음악·효과음은 외부 곡/샘플/음성 없이 이 영상에 맞춰 절차적으로 제작했습니다. 유행곡을 가져온 것이 아니며 플랫폼 권리 판정이나 광고 심사 통과를 보장하지 않습니다. 음악을 교체할 때에는 일반 게시/브랜드 홍보/유료 광고의 실제 사용 범위를 확인하세요. 인스타그램에서 재생 가능한 곡 또는 “original audio” 표기가 있다는 이유만으로 광고 사용 허가가 생기는 것은 아닙니다. [Meta 음악 이용 안내](https://www.facebook.com/help/instagram/402084904469945)

앱 화면은 실제 Compose 화면 함수를 호스트에서 렌더한 기존 이미지의 일부를 비율대로 확대한 것입니다. 완성 네 컷 예시는 실제 CollageRenderer 출력입니다. 사진 이동·강조 링·전환은 영상 편집 효과이며 실기기 화면 녹화 또는 버튼 동작의 E2E 검증이 아닙니다. 프레임 색 예시는 필터도 함께 적용된 스타일링 결과입니다.

계정 로그인, 실제 릴스 게시, 광고 집행은 수행하지 않았습니다. 조회수·바이럴·설치 전환율을 보장하는 영상은 아닙니다.
