# Pocket 4Cut design handoff

현재 앱 UI는 `print-booth-v1` 방향으로 정리했습니다. 핵심 문법은 따뜻한 종이 배경, 잉크 블랙, 인화 레드, 얇은 구분선, 각진 사진 영역입니다.

## 구현에 반영된 범위

- 전역 `AppLayout` 반경을 2/4/6/8/12/16dp로 축소
- CTA 높이 52dp, 테두리 1dp, 컬러 글로우와 바운스 프레스 제거
- 계절 테마도 앱 셸은 paper/ink 기반으로 고정하고, 버튼·선택 표시의 강조색과 프레임 색만 계절에 따라 변경
- 시작, 홈, 컷 수 선택, 프레임 방식, 결과, 보관함을 인화지 중심 화면으로 재구성
- 사진 선택, 레이아웃, 색/계절/커스텀 프레임, 일반/상세 편집의 선택 글로우와 과한 모서리를 정리
- 촬영 화면의 보조 버튼을 사각형으로 바꾸고, 셔터의 반복 확대 효과를 제거
- 작은 화면에서도 홈의 인화지 전체를 볼 수 있게 본문 스크롤 적용
- 기존 촬영/레이아웃/편집 로직과 사용자 작업 중인 버전·레이아웃 변경은 유지

화면별 기준 이미지는 [`mockups/print-booth-v1`](mockups/print-booth-v1)에서 확인할 수 있습니다. 17개 화면 PNG, 스타일 보드, 전체 보기, 편집 원본을 제공합니다.

이 이미지는 HTML로 렌더링한 **디자인 기준 시안**입니다. Android 실행 화면 캡처가 아니며 사진은 배치를 확인하기 위한 자리 표시자입니다. 실제 화면은 기기 크기, 데이터, 선택한 테마에 따라 달라집니다.
