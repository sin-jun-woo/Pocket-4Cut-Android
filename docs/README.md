## GitHub Pages 최초 설정 (1회)

1. https://github.com/sin-jun-woo/Pocket-4Cut-Android/settings/pages
2. **Build and deployment** → **Source**: `GitHub Actions`
3. **Actions** 탭에서 `GitHub Pages` 워크플로 실행 완료 대기 (또는 `main`에 푸시 시 자동 실행)
4. 위 URL이 404면 1~3분 후 새로고침

**레포가 비공개**인 경우: Pages 설정에서 사이트 공개 범위를 확인하세요 (무료 플랜은 공개 Pages만 외부 접근 가능).
