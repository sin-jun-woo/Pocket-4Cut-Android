> 최대 4,000자.

집에서도, 방에서도, 친구들이랑 술자리에서도 —
오프라인 인생네컷 부스 경험을 그대로 가져온 모바일 포토부스 앱이에요.

줄 서고, 매장 찾고, 한 번 찍을 때마다 돈 내는 번거로움 없이
앱 하나로 찍고 → 고르고 → 꾸미고 → 공유까지 끝!

🎬 실제 부스 같은 촬영 경험

• 2컷 / 4컷 / 6컷 중 원하는 구성 선택
• 4~10장 자동 연속 촬영 (구성에 따라 자동 조절)
• 촬영 전 카운트다운으로 준비 시간 제공
• 전면 카메라 기본 — 셀카·단체샷 모두 OK
• 촬영 중 진행 표시로 몇 번째 컷인지 한눈에 확인

🖼️ 마음에 드는 컷만 골라서 완성

• 원하는 장수만큼 정확히 선택 (2 / 4 / 6장)
• 선택 순서가 번호로 표시돼서 배치가 헷갈리지 않아요
• 세로 2컷, 클래식 4컷, 그리드 4컷, 필름 스타일 가로 4컷 등

• 텍스트 · 이모지 · 스티커를 자유롭게 배치하는 나만의 프레임 편집
• 나눔, 카페24, 배민 등 13종 한국어 폰트 지원

## 6. Play Console 붙여넣기 가이드

| Play Console 필드 | 이 문서 섹션 |
|-------------------|--------------|
| 짧은 설명 | **§1. 짧은 설명** |
| 전체 설명 | **§3. 앱 소개 — 전체 설명** |
| 출시 노트 (What's New) | **§2. 출시노트** |

### 팁

- **첫 출시**면 §2 + §3 둘 다 쓰면 됨.
- **이후 업데이트**는 §2만 갱신하면 됨. (버전별로 날짜·내용 추가)
- 이모지는 Play Store에서도 잘 보이지만, 과하면 스팸처럼 보일 수 있어서 §2 정도만 유지하는 걸 추천.
- §3 전체 설명은 4,000자 제한 — 현재 약 1,400자 수준이라 여유 있음.
