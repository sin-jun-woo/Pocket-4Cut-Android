## 스토어 자료 점검 목록

- 앱 이름 표기는 `Pocket 4Cut`으로 통일한다.
- 스크린샷에는 카메라와 `앨범에서 만들기` 두 입력 방식을 모두 포함한다.
- 2·4·6컷, 사진별 자르기, Everyday Editions 88종, 작업 보관함을 실제 앱 화면으로 보여준다.
- 11개 직접 기록 테마의 날씨·위치·D-Day·횟수는 자동 입력 기능으로 표현하지 않는다. 사용자가 기존 문구·날짜 기능으로 직접 입력한다.
- 88종 정적 디자인 납품물과 앱에서 동적으로 조합하는 런타임 프레임을 혼동하지 않는다.
- Play Console 업로드 전에 `versionCode 6` 사용 가능 여부, upload certificate, 데이터 안전성 양식, 최종 AAB 해시를 다시 대조한다.
